I'm kind of planning these features for now:

1. Visualiser and controls
    - render the currently running algorithm or data structures
    - provide controls such as step, pause, resume, restart, and playback speed
    - useful stats like comparisons, swaps, operations, memory, collection size

2. Logging
    - terminal-style logs in a dedicated window - could just be a `tail` on a `.log`
    - allow user to inspect execution details without cluttering the visualisation
